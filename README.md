# CareerBot - Rule-Based Career Guidance Chatbot

CareerBot is a Python-based rule-driven chatbot designed to provide basic career guidance to students and job seekers.

The project uses predefined intents, career data, recommendation logic, and skill-gap analysis to help users explore suitable career paths and identify skills they may need to learn.

## Features

- Rule-based career guidance chatbot
- Greeting and general career conversations
- Internship guidance
- Skill development suggestions
- Resume preparation tips
- Interview preparation guidance
- Career selection guidance
- Personalized career recommendations
- Skill-gap analysis
- Personalized learning path
- Clean command-line interface
