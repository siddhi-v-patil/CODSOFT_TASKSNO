# AI Image Captioning

An AI-powered image captioning application developed as part of my CodSoft Artificial Intelligence Internship.

The application allows users to select an image and automatically generates a meaningful text description using a pre-trained image captioning model.

## Internship Task

- **Internship:** CodSoft AI Internship
- **Task:** Task 3 – AI Image Captioning
- **Domain:** Artificial Intelligence
- **Language:** Python

## Project Overview

Image captioning combines Computer Vision and Natural Language Processing to understand the content of an image and generate a natural-language description.

This project provides a simple graphical interface where users can:

1. Select an image from their computer.
2. View the selected image.
3. Process the image using an AI model.
4. Generate an automatic image caption.
5. Display the generated caption in the application.

## Features

- Image selection through a graphical interface
- AI-based image analysis
- Automatic caption generation
- Image preview
- User-friendly interface
- Success/error status messages
- Pre-trained deep learning model
- CPU-compatible execution
