# Tic-Tac-Toe AI

An intelligent Tic-Tac-Toe game built in Python using the **Minimax algorithm**. 
The project allows users to play against an AI and also provides AI-vs-AI gameplay for demonstrating game-theory decision making.

## Project Overview

This project implements an AI-powered Tic-Tac-Toe game where the computer analyzes possible moves and selects the best move using the Minimax algorithm.

The goal of the project is to understand:

- Game theory
- Decision making
- Search algorithms
- Minimax algorithm
- Recursive problem solving
- AI-based gameplay

## Features

### 1. Human vs AI
Play Tic-Tac-Toe against an intelligent AI opponent.

### 2. Difficulty Levels
The game provides different AI difficulty levels, allowing players to choose the level of challenge.

### 3. AI vs AI Battle
Two AI players can compete against each other automatically for multiple games.

### 4. AI Demonstration
Watch the AI make moves automatically and understand how the decision-making process works.

### 5. Score Tracking
The AI battle mode keeps track of:

- AI Player 1 wins
- AI Player 2 wins
- Draws

### 6. Minimax Algorithm
The AI evaluates possible future moves and selects the move that provides the best possible outcome.

## How It Works

The game represents the board using a 3×3 grid.

For the AI's turn:

1. The current board state is analyzed.
2. All possible moves are generated.
3. The Minimax algorithm explores future game states.
4. Each possible outcome is evaluated.
5. The AI selects the move with the highest possible score.
6. The game continues until a player wins or the board becomes full.
